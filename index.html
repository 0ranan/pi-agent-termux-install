安装 SkillHub（技能商店）
  1. 一键安装:
    $ curl -fsSL https://skillhub-1388575217.cos.ap-guangzhou.myqcloud.com/install/install.sh | bash

🌐 安装 pi-web（Web 界面）

已安装 npm 包: @agegr/pi-web · 端口: 30141

pi-web 是 pi-agent 的 Web 图形界面，基于 Next.js 构建。

安装步骤
  1. 全局安装 pi-web:
    $ npm install -g @agegr/pi-web@latest
  2. 验证安装:
    $ pi-web --version # 本机: 0.8.2
  3. 启动服务（前台）:
    $ pi-web
  4. 后台启动（推荐，Termux 专用）:
    $ nohup pi-web > ~/pi-web.log 2>&1 &
  5. 访问: 浏览器打开 http://localhost:30141
📋 本机参考信息
pi-web 已注册为系统服务，通过 service-manager 管理:
service-skill start pi-web — 启动
service-skill stop pi-web — 停止
service-skill log pi-web — 查看日志
sss — 查看所有服务状态

🛠️ 服务管理（service-manager）

管理 Termux 中的后台服务，如 pi-web、SSH、code-server 等。

常用命令
$ service-skill status # 查看所有服务状态 $ service-skill start 服务名 # 启动服务 $ service-skill stop 服务名 # 停止服务 $ service-skill log 服务名 [行数] # 查看日志 $ service-skill ports # 查看端口清单 $ service-skill add 名称 "命令" 端口 # 添加新服务
