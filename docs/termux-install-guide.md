# 📦 Termux 下载与安装

> 环境：Termux 0.118.3 (F-Droid) / arm64-v8a (aarch64)

## 下载

- 文件：`termux-app_v0.118.3.apk`（109MB）
- 架构：arm64-v8a (aarch64)
- 来源：F-Droid 官方构建

## 安装步骤

1. 点击下载 APK
2. 在通知栏或下载目录找到 APK 文件
3. 点击安装（需开启「允许安装未知来源应用」）
4. 安装完成后打开 Termux

## 初始化

```bash
# 初始化存储权限
termux-setup-storage

# 更新源（换源加速）
pkg update
```
